# EmdashCMS

## EmdashCMS

Use this space to document how EmdashCMS works, how teams publish with it, and how it fits into your stack.

### Start here

A strong EmdashCMS docs set usually answers three questions:

1. What is it?
2. How do I set it up?
3. How do I use it day to day?

### Recommended structure

Build out these sections next:

#### Overview

Explain what EmdashCMS is, who it is for, and the problem it solves.

#### Quickstart

Show the fastest path to a working setup. Keep it short. Use one example.

#### Core concepts

Define the main objects, workflows, and permissions model.

#### Content workflow

Document how content moves from draft to review to publish.

#### Configuration

List required settings, environment variables, and defaults.

#### Integrations

Explain how EmdashCMS connects to your frontend, APIs, and external tools.

### Suggested first pages

* Product overview

* Create and publish content
